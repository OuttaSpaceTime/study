## Query 1 (08:24)

- **Question:** Pragmatic Programmer Topic 10 challenge: how do multiple inheritance (C++), multiple interfaces (Java) and mixins (Ruby) affect orthogonality? Multiple inheritance vs multiple interfaces? Delegation vs inheritance?
- **Wiki hits:** none (nearest, coupling in general: [[software-design/splitting-responsibilities]])
- **Card hits:** cmne7y4uf03yx0msoxzx8wpiv (What is the principle of orthogonality in software design?); nothing on inheritance, delegation or mixins
- **Web check:** confirms. Effective Java Item 18 InstrumentedHashSet counts 6 instead of 3 because HashSet.addAll self-uses add, and forwarding/composition is the fix (https://blogs.oracle.com/javamagazine/post/java-inheritance-composition). Topic 31 "Inheritance Tax" alternatives are interfaces/protocols, delegation, mixins/traits; only secondary summaries were found, not the book text (https://www.oreilly.com/library/view/the-pragmatic-programmer/9780135956977/f_0052.xhtml).
- **Source:** memory
- **Answer:** Multiple implementation inheritance lowers orthogonality (fragile base class, diamond, parents now interact). Multiple interfaces raise it (contracts only). Mixins sit in between (implementation plus hook dependency on the host). Delegation beats inheritance (public interface only, swappable), shown by InstrumentedHashSet.
