## Session 1 — Change (09:35)
- **Files:** `.claude/settings.json`, `.claude/hooks/session-log-check.sh`
- **Change:** Added a `SessionEnd` hook that pipes the transcript path into a background `claude -p` call to decide whether today's log needs an entry and append one if so. Hook script writes diagnostics to `/tmp/study-session-log-check.diag` and stdout/stderr to `/tmp/study-session-log-check.log`. Permissions scoped to `Read/Glob/Grep` plus `Edit`/`Write` under `logs/**` (both relative and absolute forms).
- **Why:** Manual end-of-session logging was getting missed; the hook automates the "did this session need a log entry?" check on every chat close.

## Session 2 — Change (10:30)
- **Files:** `.claude/hooks/session-log-check.sh`
- **Change:** Iterated on the SessionEnd hook after first run failed silently. Switched the prompt from positional `claude -p "<prompt>"` to stdin-piped (`printf ... | claude -p`) to avoid the variadic `--allowedTools` swallowing the prompt. Added `--verbose` so denials surface as real Claude Code messages rather than the inner agent's prose paraphrase. Swapped `--permission-mode default` → `acceptEdits` because headless `-p` can't prompt, so `default` deny-fallbacks silently. Prompt now also instructs the inner agent to pass absolute paths to Write/Edit so the `logs/**` permission patterns match reliably.
- **Why:** First test runs showed the hook firing but producing no log entries. Advisor flagged that I was reading the agent's prose ("permission grant isn't matching") as a real error message — fixed by making diagnostics actually reflect Claude Code's denial output, then addressing the underlying headless-mode permission default.

## Session 3 — Change (13:20)
- **Files:** `.claude/hooks/session-log-check.py` (new), `.claude/settings.json`
- **Change:** Replaced `SessionEnd` + `claude -p` hook with a `Stop` hook backed by a lightweight Python script. The script reads the transcript for any `Write`/`Edit` calls under `logs/`, returns `{"decision": "block", "reason": "..."}` once if none found (using a `/tmp` lockfile to prevent a second block), and approves otherwise. No subprocess Claude is spawned.
- **Why:** The `SessionEnd` → `claude -p` pattern caused an infinite loop: each spawned session ended, fired `SessionEnd` again, spawned another session, etc. — draining the usage quota. The `Stop` hook fires on the main session before it exits, so the main agent writes the log directly with no recursion risk.
