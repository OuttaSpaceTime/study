## Session 3 — Change (13:20)
- **Files:** `.claude/hooks/session-log-check.py` (new), `.claude/settings.json`
- **Change:** Replaced `SessionEnd` + `claude -p` hook with a `Stop` hook backed by a lightweight Python script. The script reads the transcript for any `Write`/`Edit` calls under `logs/`, returns `{"decision": "block", "reason": "..."}` once if none found (using a `/tmp` lockfile to prevent a second block), and approves otherwise. No subprocess Claude is spawned.
- **Why:** The `SessionEnd` → `claude -p` pattern caused an infinite loop: each spawned session ended, fired `SessionEnd` again, spawned another session, etc. — draining the usage quota. The `Stop` hook fires on the main session before it exits, so the main agent writes the log directly with no recursion risk.
