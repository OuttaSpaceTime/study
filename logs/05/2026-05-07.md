## Query 1 (10:15)

**Wiki hits:** none
**Card hits:** none
**Web check:** confirms — https://reactivex.io/documentation/contract.html
**Source:** research
**Answer:** An observable emits zero or more next values, then at most one terminal event (error or complete), after which nothing more is emitted.

## Query 2 (13:00)
**Question:** why do we need to call subscribe on an observable?
**Wiki hits:** none
**Card hits:** none
**Web check:** confirms — https://reactivex.io/documentation/operators/subscribe.html
**Source:** research
**Answer:** Observables are lazy — the producer function does not run until subscribe is called; each subscription is an independent execution.
