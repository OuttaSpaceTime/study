## Query 1 (HH:MM)
- **Question:** Is `pluck` chainable in ActiveRecord?
- **Wiki hits:** none
- **Card hits:** none
- **Web check:** confirms — Rails Guides state explicitly: "pluck triggers an immediate query, and thus cannot be chained with any further scopes, although it can work with scopes already constructed earlier"; returns a plain Ruby Array, not an ActiveRecord::Relation; `Customer.pluck(:first_name).limit(1)` raises NoMethodError. URL: https://guides.rubyonrails.org/active_record_querying.html
- **Source:** memory (confirmed by web)
- **Answer:** `pluck` is terminal — chain scopes before it freely, nothing can be chained after it since it returns a plain Array
