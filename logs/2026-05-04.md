## Query 1 (06:29)
- **Question:** what is the difference of relearning vs review?
- **Wiki hits:** none
- **Card hits:** none
- **Web check:** confirms — ts-fsrs source (`packages/fsrs/src/models.ts` State enum {New=0, Learning=1, Review=2, Relearning=3}; `packages/fsrs/src/impl/basic_scheduler.ts` reviewState Again branch sets `State.Relearning` + `lapses += 1`; learningState reuses `this.last.state` so Again during Relearning stays in Relearning without incrementing lapses; applyLearningSteps uses minute-scale `scheduled_minutes < 1440` steps then promotes back to `State.Review`). https://github.com/open-spaced-repetition/ts-fsrs/blob/main/packages/fsrs/src/impl/basic_scheduler.ts
- **Source:** research
- **Answer:** Comparison table — Review = long days-scale interval after graduation, no lapses bump on entry, stability grows on success; Relearning = entered only via Again-from-Review (lapses += 1, stability cut to post-lapse min), short minute/hour steps from `relearning_steps`, exits back to Review on Good/Easy (or after step completion); Again during Relearning resets the relearning step and does NOT increment lapses again.
