## Prediction
`github.com` will serve HSTS with `preload` and `includeSubDomains` set, with a long `max-age` (guessed ~2 years per wiki recommendation).

## Command
```bash
curl -sI https://github.com | grep -i strict-transport-security
```

## Output
```
strict-transport-security: max-age=31536000; includeSubdomains; preload
```

## Takeaway
Prediction was directionally right on directives but wrong on `max-age`: GitHub uses 1 year (31536000s), not the 2 years the wiki recommends. The header is just a plain response header on HTTPS — no magic. The security comes from (a) browser persistence of the rule in its HSTS store and (b) TLS authenticating the header's origin on the first successful HTTPS reply.
